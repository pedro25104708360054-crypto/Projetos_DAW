COMO RODAR NO XAMPP

1. Extraia a pasta site_ihm_com_admin.
2. Copie a pasta para: C:\xampp\htdocs\
3. Abra o XAMPP e inicie Apache e MySQL.
4. Acesse: http://localhost/phpmyadmin
5. Importe o arquivo banco.sql.
6. Abra: http://localhost/site_ihm_com_admin/index.php
