# Sistema Ardone

Projeto desenvolvido para a avaliação final da disciplina de Desenvolvimento de Aplicações Web.

O sistema foi criado em PHP e MySQL para auxiliar no controle de um salão de beleza.

## Funcionalidades

- Login do administrador
- Login do cliente
- Cadastro de clientes
- Cadastro de funcionários
- Cadastro de serviços
- Controle de agendamentos
- Marcação de horário pelo cliente
- Filtros nas listagens administrativas

## Organização do projeto

- `config/`: conexão e configurações
- `includes/`: autenticação, validação e funções auxiliares
- `views/`: telas do sistema
- `actions/`: ações de cadastro, edição e exclusão
- `api/`: retorno de horários disponíveis
- `assets/`: CSS, JavaScript e imagens
